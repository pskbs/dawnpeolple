- ⚠️ **탭바 재평가(2026-09-23)** — 기존에 "TDS 플로팅 탭바로 반드시 교체 필요(❌)"라고 적어뒀던 건 재확인 결과 부정확했음. 공식 문서(`design/components/tabbar.html`, 2026-09-23 조회): "탭바는 필수 컴포넌트가 아니며, 쓴다면 **플로팅 형태**를 따라야 하고(토스 메인 앱 하단 탭과 겹치면 헷갈릴 수 있어서), 2~5개 탭까지 가능"이 전부이고 별도 npm 컴포넌트 강제 사항은 확인 안 됨. 지금 `TabBar.tsx`/`TabBar.css`는 이미 화면 하단에서 **떠 있는 캡슐 형태**(`position:fixed`+`border-radius:999px`+글래스+그림자, 화면 전체 폭이 아님)라 요건에 부합할 가능성이 높음. **다만 아이콘 스타일·정확한 치수 같은 세부 규정까지는 확인 못 했으니, 검수 신청 전 육안으로 공식 예시와 비교 확인 권장.**
