## 접근/실행·보안
- ✅ 외부 코드 실행(eval 등) 없음 — 코드 전체 grep 확인.
- ✅ CSR(SPA) 빌드 방식 — Vite+React SPA, SSR 없음.
- ✅ HTTPS만 사용 — Supabase URL, 메일 발송 모두 https.
- ❌ **`@apps-in-toss/web-framework` SDK·`ait` CLI 미설치** — 지금 프로젝트는 순수 Vite 프로젝트이고, 토스가 요구하는 전용 빌드 파이프라인(`ait build`/`ait deploy`, `granite.config.ts`)이 없음. `build:toss` 스크립트도 `build:web`과 동일한 placeholder. **App key 발급 후 다음 작업으로 진행 예정.**

## 서비스 동작
- ✅ 라이트 모드 고정(`hybrid` 테마, `night`는 미사용 — 2026-09-22 결정).
- ✅ 세션 유지(Supabase `persistSession`+`autoRefreshToken`).
- ✅ 뒤로가기 동작 일관(`useGoBack`).
- ✅ 진입 시 강제 바텀시트·강제 액션 없음.
- ✅ 화면마다 명확한 종료(뒤로가기) 방법 있음.
- ✅ 제스처 줌 비활성화 — `index.html` viewport meta에 `maximum-scale=1.0, user-scalable=no` 추가(2026-09-22).
- ❌ 권한(카메라 등) 요청을 사용 시점에 하는지 — 현재 사진 첨부는 `<input type=file>` 사용 중이라 OS 기본 동작을 따름(문제 없을 가능성 높지만 앱인토스 SDK로 전환 시 `Device.openCamera()` 등으로 바뀔 수 있어 재확인 필요).
- ❌ 공유 기능(`intoss://` 스킴) — 미구현. 지금은 공유 버튼 자체가 없음.

## 토스 로그인
- ❌ 토스 로그인 자체가 미구현(현재 Supabase 이메일 로그인만 있음). 미니앱은 토스 로그인만 허용되므로 앱인토스 빌드에서는 이메일 로그인 화면을 숨기고 토스 로그인으로 교체해야 함.
- ❌ mTLS 서버 연동(`api/` PoC) 미구현 — **🔒 App key/시크릿 발급, mTLS 인증서 발급은 콘솔에서 사용자가 진행해야 다음 단계 가능.**
- ❌ 서비스 소개 페이지 노출, 약관 URL 노출은 `/terms` `/privacy` 페이지 자체는 있음(✅) but 토스 로그인 연동 화면에서 노출하는 연결은 아직 없음.
- ❌ 연동 해제(UNLINK) 웹훅 수신·데이터 삭제 자동화 — 회원탈퇴 RPC(`delete_my_account`)는 있지만 토스 쪽 UNLINK 콜백과 연결되지 않음.
- ✅ 대체 로그인 수단 없음 요건 — 토스 로그인 도입 시 앱인토스 빌드에서는 이메일 로그인을 숨길 계획(설계는 돼 있고 구현은 Phase 2).
