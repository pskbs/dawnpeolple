> 버전: 이용약관 `draft-2`, 개인정보 처리방침 `draft-2` (2026-09-22 작성). 가입 시 동의 버전은 `terms_agreements`에 저장돼요.

## 사용자가 채워야 할 빈칸 `[입력 필요]`
- 시행일
- 사업자등록번호, 사업장 주소, 통신판매업 신고번호(해당 시)

## 이용약관
1. **회사의 지위(제13조)**: 오프라인 모임의 당사자가 아니라는 조항과 면책 범위가 「약관규제법」상 유효한지(고의·중과실 예외는 넣어둠).
2. **메시지 열람(제15조)**: "신고 접수 시 신고 처리에 필요한 범위에서 확인할 수 있다"는 조항이 통신비밀보호법·개인정보보호법상 허용되는 범위인지, 별도 동의가 필요한지. (현재 관리자 열람 기능은 구현되어 있지 않음)
3. **이용 제한 절차(제12조)**: 경고→일시정지→영구정지, 긴급 시 즉시 정지, 이의제기 30일 — 기간과 통지 방법 적정성.
4. **게시물 이용 허락(제10조)**: 탈퇴 후 다른 회원이 인용한 부분 예외 조항의 적정성.
5. **약관 변경 공지 기간(제3조)**: 7일/30일 기준, 개별 통지 방법(웹은 이메일 원문을 저장하지 않는 원칙과 충돌 여부 — 현재 웹 로그인은 Supabase Auth에 이메일이 저장됨).
6. **관할(제19조)**: 소비자 보호 관점에서 관할 조항 표현.
7. **만 19세 이상 확인**: 웹은 출생연도 자기 입력 + 체크박스만으로 충분한지(앱인토스는 토스 생일 정보로 판별 예정).
8. **포지셔닝**: DM·팔로우·참석 전 성별/연령대 집계 공개가 추가되어 "만남 중개 서비스"로 분류될 위험이 없는지(요청서 1장 포지셔닝 참고).

## 개인정보 처리방침
1. **수집 항목 정합성(제2조)**: 실제 구현과 일치 확인 — 이메일(웹 로그인, Supabase Auth 보관), 성별·출생연도, 지역, 프로필 사진·한줄소개(선택), 첨부 파일, 메시지 내용, 팔로우 관계.
   - CLAUDE.md 절대규칙 4("이메일 원문 저장 금지")와 웹 1단계 이메일 로그인의 충돌 — 앱인토스 토스 로그인 전환 후 정리 필요.
2. **보유 기간(제4조)**: 접속 기록 보관 근거(통신비밀보호법 3개월 등)와 실제 Supabase/Vercel 로그 보관 기간 확인.
3. **국외 이전(제6조)**: Supabase·Vercel·Anthropic의 이전 국가, 데이터센터 위치, 이전 일시·방법, 수탁자 연락처 기재. 「개인정보 보호법」 제28조의8 요건 충족 여부.
4. **공개 정보(제3조)**: 비회원에게도 프로필·게시물이 공개된다는 점, 참석 전 성별·연령대 "집계" 공개가 개인 식별 위험이 없는지(참석자 1명일 때 사실상 특정될 수 있음 — 검토 필요).
5. **사진 메타데이터**: 업로드 사진의 EXIF 위치정보를 서버에서 제거하지 않음 → 안내 문구로 대체 중. 제거 기능 도입 여부.
6. **광고 SDK(제10조)**: 앱인토스 광고 도입 시 쿠키/광고 식별자 항목 추가 필요.
7. **파기(제7조)**: 탈퇴 시 스토리지 파일 즉시 삭제(구현됨), 백업본 보관 기간(Supabase 백업 정책) 기재 여부.
