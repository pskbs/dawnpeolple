# 디자인 참고 분석 (design.png)

원본 위치: `design concept/design.png` (원본은 그대로 두고 `docs/design-reference/design.png`로 복사함)

## 이미지 내용
로그인 화면 목업. 파스텔 보라색 배경에 구름 3D 소품, 왼쪽에 후드 입은 3D 클레이 스타일 캐릭터(소녀), 오른쪽에 흰색 카드형 로그인 폼(음표 아이콘, "Welcome Back!" 타이틀, 아이디/비밀번호 알약형 입력창, 보라색 알약형 CTA 버튼, 구글/애플/페이스북 소셜 로그인 아이콘).

## 가져올 질감·구성 원리 (요청서 10-2 기준)
- **말랑한 3D(클레이) 질감**: 카드·아이콘·버튼 모두 부드러운 그라데이션 + 안쪽 하이라이트 + 넓게 퍼지는 낮은 그림자. 딱딱한 flat 디자인이 아니라 손에 잡힐 듯한 입체감.
- **떠 있는 큰 라운드 카드**: 로그인 폼 카드의 모서리 반경이 매우 크고(≈32px+), 배경과 분리되어 떠 있는 느낌(그림자로 깊이 표현).
- **알약(pill) 모양 입력창·버튼**: 입력창과 버튼 모두 완전한 캡슐형(border-radius: 999px 수준).
- **둥근 사각형 아이콘**: 음표 아이콘 배지가 입체감 있는 둥근 사각형(squircle)에 담겨 있음.
- **캐릭터가 카드에 기대는 구도**: 캐릭터가 카드 왼쪽에 걸쳐 서 있어 카드와 캐릭터가 겹치며 깊이감을 만듦 → 새벽사람들의 인트로 화면에도 이 구도를 적용(마스코트가 카드 옆/위에 걸쳐 있는 구성).
- **배경 3D 소품**: 원본은 구름 위주. 우리는 **구름 → (그대로 유지 가능) + 달 + 별**로 대체/추가.
- **톤 매핑**: 원본 파스텔 보라 → 우리는 **네이비(#12173A) + 라벤더(#A99BFF) + 달빛 노랑(#FFD66B)**로 치환.

## 그대로 따라 하지 않는 것
- 캐릭터(인물) 자체, 전체 구도, 문구("Welcome Back!" 등), 브랜드 아이콘(음표)은 복제하지 않음. "새벽이들" 마스코트(초승달 후드 캐릭터)를 별도로 새로 디자인.
- 앱인토스 안에서는 소셜 로그인 3종 대신 **토스 로그인 버튼 하나만** 배치(카드 구조는 참고하되 버튼 수는 다름).

## 적용 화면
- 인트로/로그인 화면: "카드 + 캐릭터 + 큰 CTA" 원리 그대로. 카드는 hybrid 테마에서는 밝은 카드, night 테마에서는 딥네이비 카드+테두리 글로우.
- 벙개 카드 헤더, 빈 화면(empty state), 배지: 동일한 클레이 질감 원리 적용, 리스트/본문 등 일반 UI는 절제된 낮은 그림자로 대비.

# 디자인 참고 분석 (design2.png)

원본 위치: `design concept/design2.png` (원본은 그대로 두고 `docs/design-reference/design2.png`로 복사함)

## 이미지 내용
연보라 배경의 AI 챗봇 앱 UI킷 스크린 3장(홈/음성채팅/스마트챗). 글로시한 그라데이션 구체(블롭) 일러스트, 캡슐형 플로팅 하단 탭바(가운데 아이템이 원형으로 강조), 알약형 검색창(왼쪽에 작은 구체 아이콘), 채팅 말풍선(내 말풍선은 프라이머리 색 채움, 상대 말풍선은 흰 카드+아바타), 아이콘 전용 리액션 행(복사/좋아요/싫어요/읽기).

## 가져올 질감·구성 원리 (2026-09-21 리디자인 요청 기준)
- **캡슐형 플로팅 탭바 + 원형 강조 배지**: 활성 탭만 원형 그라데이션 배지로 띄우고, 나머지는 고스트 아이콘. 라벨 텍스트 없이 아이콘만(접근성은 `aria-label`로 보완).
- **글로시 그라데이션 블롭 아트**: 단색 배경 대신 겹친 radial-gradient로 만든 부드러운 구체를 히어로/빈 화면 장식에 사용. **애니메이션·파티클은 CLAUDE.md 규칙상 금지**라 정적 배치만 적용.
- **프로스티드 글래스 카드**: 반투명 배경 + blur + 얇은 하이라이트 테두리. 로그인 카드·탭바·게스트 안내 배너 등 "떠 있는" 느낌이 필요한 면에 적용.
- **아이콘 전용 액션 행**: 텍스트 필 버튼("좋아요 12") 대신 아이콘+숫자만(SNS 피드의 좋아요/댓글 행에 적용).
- **컬러 그림자**: 버튼/배지 그림자가 검정이 아니라 프라이머리 색 틴트(반투명)로 은은하게 번짐 — `--glow` 토큰으로 구현.
- **아바타 원형 배지**: 말풍선/메시지 헤더마다 원형 아바타. 우리는 프로필 사진이 없으므로 닉네임 첫 글자를 그라데이션 원형 배지에 표시하는 방식으로 대체.

## 색상 — 그대로 따라 하지 않음
원본은 전면 연보라(#EDE9FF 계열) 배경이지만, **CLAUDE.md 절대규칙 2번(라이트모드 금지, night 테마는 전면 딥네이비, OS 다크모드 무시)** 및 위 `design.png` 분석에서 이미 확정한 "파스텔→네이비+라벤더+달빛노랑" 치환 원칙과 정면으로 충돌함. 2026-09-21 사용자에게 확인한 결과 **색상은 기존 네이비(#12173A)+라벤더(#A99BFF)+달빛노랑(#FFD66B) 팔레트를 유지**하고, 위에 정리한 질감·구성 문법만 가져오기로 결정(`docs/decisions.md` 기록).

## 적용 화면
- 탭바(`TabBar`): 아이콘 전용 캡슐 + 활성 원형 배지.
- 수다방(`FeedPage`): 히어로를 블롭 아트로, 피드 리스트를 박스 카드 대신 구분선 기반 스레드 행으로, 좋아요/댓글을 아이콘 전용 액션으로 전환.
- 로그인(`AuthPage`): 히어로를 블롭 아트로, 카드를 글래스 패널로.
- 공용 컴포넌트(`components.css`): `.blob-art`, `.glass-panel`, `.avatar`, `.icon-action` 신설.
