# 디자인 참고 분석 (design.png)

원본 위치: `design concept/design.png` (원본은 그대로 두고 `docs/design-reference/design.png`로 복사함)

## 이미지 내용
로그인 화면 목업. 파스텔 보라색 배경에 구름 3D 소품, 왼쪽에 후드 입은 3D 클레이 스타일 캐릭터(소녀), 오른쪽에 흰색 카드형 로그인 폼(음표 아이콘, "Welcome Back!" 타이틀, 아이디/비밀번호 알약형 입력창, 보라색 알약형 CTA 버튼, 구글/애플/페이스북 소셜 로그인 아이콘).

## 가져올 질감·구성 원리 (요청서 10-2 기준)
- **말랑한 3D(클레이) 질감**: 카드·아이콘·버튼 모두 부드러운 그라데이션 + 안쪽 하이라이트 + 넓게 퍼지는 낮은 그림자. 딱딱한 flat 디자인이 아니라 손에 잡힐 듯한 입체감.
- **떠 있는 큰 라운드 카드**: 로그인 폼 카드의 모서리 반경이 매우 크고(≈32px+), 배경과 분리되어 떠 있는 느낌(그림자로 깊이 표현).
- **알약(pill) 모양 입력창·버튼**: 입력창과 버튼 모두 완전한 캡슐형(border-radius: 999px 수준).
- **둥근 사각형 아이콘**: 음표 아이콘 배지가 입체감 있는 둥근 사각형(squircle)에 담겨 있음.
- **캐릭터가 카드에 기대는 구도**: 캐릭터가 카드 왼쪽에 걸쳐 서 있어 카드와 캐릭터가 겹치며 깊이감을 만듦 → 새벽사람들의 인트로 화면에도 이 구도를 적용(마스코트가 카드 옆/위에 걸쳐 있는 구성).
- **배경 3D 소품**: 원본은 구름 위주. 우리는 **구름 → (그대로 유지 가능) + 달 + 별**로 대체/추가.
- **톤 매핑**: 원본 파스텔 보라 → 우리는 **네이비(#12173A) + 라벤더(#A99BFF) + 달빛 노랑(#FFD66B)**로 치환.

## 그대로 따라 하지 않는 것
- 캐릭터(인물) 자체, 전체 구도, 문구("Welcome Back!" 등), 브랜드 아이콘(음표)은 복제하지 않음. "새벽이들" 마스코트(초승달 후드 캐릭터)를 별도로 새로 디자인.
- 앱인토스 안에서는 소셜 로그인 3종 대신 **토스 로그인 버튼 하나만** 배치(카드 구조는 참고하되 버튼 수는 다름).

## 적용 화면
- 인트로/로그인 화면: "카드 + 캐릭터 + 큰 CTA" 원리 그대로. 카드는 hybrid 테마에서는 밝은 카드, night 테마에서는 딥네이비 카드+테두리 글로우.
- 벙개 카드 헤더, 빈 화면(empty state), 배지: 동일한 클레이 질감 원리 적용, 리스트/본문 등 일반 UI는 절제된 낮은 그림자로 대비.
